# HubCentral

### One Platform. Multiple Bookings.

[Live Demo of HubCentral](https://pranithaa-p.github.io/hubcentral/) 

## About

HubCentral is an all-in-one ticket booking platform built to bring different types of bookings into a single, easy-to-navigate experience.

Instead of switching between separate platforms for movies, events, and flights, HubCentral brings them together under one hub. The idea is simple: **one place to discover, explore, and manage different ticket booking needs.**

The project was developed as part of a hackathon, with a focus on creating a unified booking experience rather than separate websites for each category.

## What Makes HubCentral Different?

The core idea behind HubCentral is **consolidation**.

Most booking experiences are built around a single category — movie tickets on one platform, events on another, and flights somewhere else. HubCentral takes a different approach by bringing these categories together within one platform.

### Key Highlights

* **Unified Booking Experience**
  Movies, events, and flights are brought together instead of being split across different platforms.

* **Multiple Booking Categories**
  Users can access MovieHub, EventHub, and AirHub from the same platform.

* **Simple Navigation**
  The interface is designed around a central hub so users can move between different services without having to learn a completely different platform each time.

* **User & Admin Sections**
  The project includes dedicated interfaces for both users and administrators.

* **Location-Based Pages**
  The project includes dedicated pages for different states, supporting a more localized booking experience.

## Booking Categories

### MovieHub

A dedicated section for exploring movie-related ticket booking options.

### EventHub

A centralized section for discovering and accessing event-related bookings.

### AirHub

A flight booking section integrated into the same platform.

## Getting Started

To run HubCentral locally:

```bash
git clone https://github.com/pranithaa-p/online_ticket_booking_hackathon.git
cd online_ticket_booking_hackathon
```

Open `index.html` in a browser to explore the project.

## Project Structure

The project is organized as a multi-page web application containing:

* Movie booking pages

* User interface
* Admin interface
* State-specific pages
